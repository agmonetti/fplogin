# SDDM patch series

The series targets SDDM `v0.21.0` (`63780fcd79f1dbf81a30eef48c28c699ab15aded`). Apply it after the pinned Arch CMake compatibility change `228778c2b4b7e26db1e1d69fe484ed75c5791c3a`; this series does not include or replace that packaging change.

Apply in listed order with `git apply` from the SDDM source root. The patch adds request/method identity, deferred winner authorization, concurrent password/fingerprint helpers, greeter control IPC, peer-PID verification, bounded nonblocking helper framing, stale-result rejection and queued context replacement. PAM packaging and QML/theme behavior remain out of scope.

The patch includes the earlier five security-review corrections, the production winner gate, and a remediation for the helper socket-disconnect/SIGKILL race, destructor-time timers, and logind session reuse. `AuthAttemptGate` covers winner and cancellation order; `AuthTransport` includes a real `Auth`/socket exchange with a synthetic helper that disconnects after authorization and exits 0. The final physical-reader matrix R01–R16 passed with genuine guest PAM and the Synaptics `06cb:00bd` reader. Sprint 1 is **accepted and closed** by the [2026-10-04 independent review](../../../docs/reviews/sprint-1.md#2026-10-04-sol-independent-acceptance-review--sprint-1-gate). Sprint 2 is authorized; its [execution plan](../../../docs/SPRINT_2_EXECUTION_PLAN.md) keeps this accepted patch intact and adds the greeter changes in a subsequent patch.
