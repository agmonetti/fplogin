# SDDM patch series

The series targets SDDM `v0.21.0` (`63780fcd79f1dbf81a30eef48c28c699ab15aded`). Apply it after the pinned Arch CMake compatibility change `228778c2b4b7e26db1e1d69fe484ed75c5791c3a`; this series does not include or replace that packaging change.

Apply in listed order with `git apply` from the SDDM source root. The patch adds request/method identity, deferred winner authorization, concurrent password/fingerprint helpers, greeter control IPC, peer-PID verification, bounded nonblocking helper framing, stale-result rejection and queued context replacement. PAM packaging and QML/theme behavior remain out of scope.

The patch includes source corrections for all five blockers recorded in `docs/reviews/sprint-1-security-review.md` after review of `4312169`, plus a production-path winner gate and focused Qt checks. The gate check exercises both winner orders, simultaneous callbacks, cancellation/loser-exit ordering, stale identity, and invalidation. The transport check launches the actual `Auth` process/socket implementation against an unprivileged synthetic wire peer (not PAM), covering split/coalesced/partial frames, foreign peer PID rejection, stale frame rejection, and the old-timer/retry boundary. A clean pinned patch applies, and a Qt 6 full source build plus CTest passes 6/6 in a disposable Arch container. A separate private-PAM probe confirms account denial and bounded real reader cancellation without changing host services. These checks are not a patched SDDM login/session, autologin, X11-cookie, or physical-reader winner-barrier test. Sprint 1 remains **unaccepted**; see `docs/reviews/sprint-1.md` and the independent security review.
